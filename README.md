🍄 Bounceback

Ein kleiner 2D-Plattformer, gemacht mit Godot 4.7. Du spielst einen Pilz, der durch ein Level hüpft und die Zielfahne erreichen muss.

Entstanden für die Hack Club Haven Challenge in Dortmund.


Spielen

Das Spiel kann direkt auf itch.io gespielt werden: 
https://simon-maunzer.itch.io/bounce-back

Steuerung
Aktion	Taste
Laufen	A / D oder Pfeil links / rechts
Springen	Leertaste, W oder Pfeil hoch

Tipp: Halte die Sprungtaste gedrückt, um höher zu springen. Kurzes Antippen ergibt einen kleinen Sprung.

Ziel

Erreiche die Zielfahne.

Projekt selbst öffnen
Godot 4.7 herunterladen und installieren.
Dieses Repository klonen oder als ZIP herunterladen.
In Godot auf Importieren klicken und die Datei project.godot auswählen.
Mit F5 starten. Die Hauptszene ist main.tscn.
